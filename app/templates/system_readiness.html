Recovery checklist

  1. Take a fresh database backup and verify its SHA-256 sidecar.
  2. Restore only into a disposable database whose identity differs from the source.
  3. Apply database migrations and run python -m pytest -q.
  4. Verify login, incident reporting, analysis, evidence, mitigation tasks, and Add Decision import in a staging environment.
  5. Record the operator, time, result, and any follow-up actions in the audit process.
